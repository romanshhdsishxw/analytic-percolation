## 📌 Описание задачи

Задача перколяции заключается в определении наличия непрерывного связного пути из открытых ячеек между противоположными границами сетки (например, от левого края к правому).

В данном проекте рассматриваются два типа случайных сред:
1. **Некоррелированные карты:** Каждая ячейка открывается независимо с вероятностью $p$.
2. **Коррелированные карты:** Ячейки открываются кластеризованно на основе управляющего параметра $\alpha$, имитируя физические структуры с корреляционной длиной.

---

## 🚀 Функциональные возможности

- **Алгоритм поиска в глубину (DFS):** Точная проверка наличия сквозного пути от одной границы до другой.
- **Генерация датасетов:** Создание тысяч карт размером $L \times L$ для различных значений концентрации $p \in [0.4, 0.8]$ и параметров корреляции $\alpha \in \{8, 6, 4, 2\}$.
- **Извлечение признаков:** Расчет базовых статистических, пространственных, корреляционных и кластерных характеристик для каждой карты (21 признак).
- **Классификация (Random Forest):** Обучение ансамбля деревьев решений со стратификацией данных.
- **Сохранение и экспортирование:** Автоматический экспорт обученной модели (`.joblib`) и предсказаний для тестовой выборки (`final.csv`).
